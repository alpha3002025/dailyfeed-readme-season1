# 주요 설계 포인트
- 스케일아웃 그룹을 Read/Write 셩격 별로 분리
- 논리적인 구조로만 분해할 경우 예상치 못한 트래픽 급증시 특정 서비스 전체가 한꺼번에 스케일아웃 되는 구조는 지양
- 멀티스레드 보다는 멀티프로세스 (kubernetes) 원칙을 고려
- 7인 8각 게임과 같은 모놀리딕 구조는 배제
- 저장소까지 분리한 완전한 MSA는 아니지만, 운영,유지보수 시 작업의 효율성을 고려한 부하 성격별 레플리케이션 그룹을 분류
